SSH Device Manager

A Python / Tkinter console for managing SSH connections and running predefined commands on remote devices, with a JSON-driven action panel and 18 built-in themes.

Source: github.com/esanacore/SSH_DeviceManager

⚠ Everything below is simulated. This page opens no socket, contacts no host, and runs no command. The device output is a scripted transcript written for this demo — not a recording of a real session. The interface is a faithful HTML re-creation of the Tkinter application, not the application itself.

Why a simulation: the real program is a desktop GUI that needs Python, Tkinter, paramiko, and a reachable SSH device before it will show you anything. This page lets you see what it does without any of that.

The application

The action buttons, their labels, tooltips and commands are generated from the project's real sections.json — the same file the program reads. The theme list is the real THEMES table from ssh_device_manager/themes.py, all 18 of them.

What drives the buttons

The panel above is not hard-coded. sections.json declares sections, buttons, labels, enabled state, tooltips and commands; the program renders them and watches the file, reloading the panel when it changes. customizer.py is a separate GUI for editing it with a live preview. This is the file used on this page, verbatim:




A command of run:<text> executes that text on the
device. __upload_template__ and __scp_file__ are built-in handlers for
SFTP uploads. __custom_command__ prompts for input.



What the real thing requires



    
  
  • Python with Tkinter — the interface is Tkinter, so a Python build that
      includes it. Installing with pip install -e . pulls paramiko for
      SSH and SFTP.
    • 
  
  • A reachable device that accepts SSH username/password authentication. The
      demo's transcript resembles a switch or router, but any SSH host works.
    • 
  
  • Your own sections.json — the shipped one is an example.
      Run python customizer.py to build the panel you actually want.
    • 
  
  • Nothing else. No server, no account, no telemetry. Profiles and host
      history are stored in a local JSON config file.
    • 




Then python SSH_DeviceManager.py, or the ssh-device-manager command
that installing provides.
